# Definition of Done

A user story is considered Done only when:

- Requirement is clearly understood.
- Acceptance criteria are defined.
- Test scenarios are identified.
- Positive scenarios are covered.
- Negative scenarios are considered.
- Relevant API tests are implemented.
- Relevant UI tests are implemented.
- Database validation is added when required.
- Security impact has been considered.
- Automation passes successfully.
- No critical or high-severity unresolved defects remain.
- Code follows framework coding standards.
- Pull Request has been reviewed.
- CI pipeline passes.
- Test evidence/report is available.
- Documentation is updated.
