# RetailHub-Project

## About the Project

RetailHub Quality Engineering Platform is a production-style
automation framework designed to demonstrate modern Quality
Engineering practices.

The project covers:

- UI Automation
- API Automation
- Database Testing
- Security Testing
- CI/CD
- Test Reporting
- AI-assisted Testing

## Technology Stack

### UI Automation
- Selenium
- Java
- TestNG
- Maven

### Modern UI Automation
- Playwright
- TypeScript

### API Automation
- REST Assured
- Playwright API

### Database
- JDBC
- SQL

### Security
- OWASP Top 10
- OWASP ZAP

### CI/CD
- GitHub Actions

### Reporting
- Allure
- Playwright HTML Reports

## Project Goal

The goal of this project is to build a maintainable,
scalable and production-style Quality Engineering framework.

## Branching Strategy

main
  |
  ├── feature/*
  ├── bugfix/*
  ├── test/*
  └── refactor/*

The main branch should always contain stable code.

New development should be performed on feature branches
and merged through Pull Requests.
